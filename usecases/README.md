# DBRetina use cases

Small, real analyses that each pose a biological question and answer it with DBRetina. Every one is reproducible:
`cd` into its directory (with the `dbretina` conda environment active) and run `bash run.sh`.

Each directory holds the derived input data (`data/`), the scripts that build the data and figures, a `run.sh`
with the DBRetina commands, and the resulting figures (`figures/`). Run artifacts (indexes, pairwise output) are
regenerated by `run.sh` and are not tracked.

| Use case | Question | Databases |
| --- | --- | --- |
| [`disease-genetics-proof/`](disease-genetics-proof/) | Do autoimmune diseases share a genetic core? (full chain + permutation test, 167 SD) | DisGeNET |
| [`autism-comorbidity/`](autism-comorbidity/) | Does autism's genetic overlap match its comorbidities? | DisGeNET |
| [`diabetes-types/`](diabetes-types/) | Type 1 vs type 2 diabetes: same name, different genetics? | DisGeNET |
| [`alzheimer-metric/`](alzheimer-metric/) | What does Alzheimer's share genes with? (why the metric matters) | DisGeNET |
| [`cancer-hallmarks/`](cancer-hallmarks/) | Are the cancer Hallmarks really independent? | MSigDB Hallmark |
| [`drug-repurposing/`](drug-repurposing/) | Do drugs reveal their mechanism through shared targets? | DSigDB |
| [`integrative-network/`](integrative-network/) | Connecting a disease to its mechanism and treatment across databases | DisGeNET + DSigDB + KEGG + Reactome + WikiPathways |

The full write-ups, with figures, are in the documentation:
<https://dbretina.github.io/DBRetina/examples/>

Source databases (DisGeNET, DSigDB, MSigDB) are not redistributed here; each README says where to get them. The
small derived gene-set files under `data/` are provided so the DBRetina steps run without them.
